LOZAN UNIFIED SYSTEM - MULTI SCHOOL

GENERAL ADMIN ACCOUNT
Username: generaladmin
Password: Admin@12345

The General Administration account is a dedicated platform-level account.
It is NOT a school account.

After importing your database / uploading this system:
1. Open setup_multischool.php?run=YES once.
2. The setup creates the schools/school_grades tables and the General Admin account.
3. Log in at index.php using the General Admin credentials above.
4. Use "Manage Schools" to create schools.
5. Use "Add School Admin" to create an Admin account and assign it to a school.
6. A School Admin only sees and manages data belonging to its assigned school.
7. New schools automatically receive Kids and Grades 1-12.

IMPORTANT:
Delete setup_multischool.php from the server after running it.
Take a database backup before upgrading.
